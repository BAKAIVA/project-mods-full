# Project Mods Full

Modpack para **Minecraft 26.1.2** com **NeoForge 26.1.2.122**.

## Instalação

1. Instale o launcher (CurseForge) e crie uma instância de **Minecraft 26.1.2 com NeoForge 26.1.2.122**.
2. Baixe o modpack na aba **Releases** deste repositório (arquivo `.zip`) e importe no launcher.
3. Se preferir montar manualmente, use a lista de mods em [`MODS.txt`](MODS.txt) e copie as pastas `config` e `kubejs` deste repositório para a sua instância.

## O que está neste repositório

| Pasta / arquivo | Conteúdo |
|---|---|
| `config/` | Configurações dos mods |
| `kubejs/` | Scripts de receitas e ajustes do pack |
| `defaultconfigs/` | Configurações padrão |
| `MODS.txt` | Lista dos mods |
| `CHANGELOG.md` | Histórico de mudanças |

Os arquivos dos mods (`.jar`) **não** estão incluídos neste repositório.
